
# Formulário de Matrícula 📝

Este projeto é um exercício prático desenvolvido durante a minha formação Full-Stack. O objetivo principal foi aplicar conceitos fundamentais de estruturação e estilização web através da construção de um formulário visualmente agradável.

## 🔗 Demonstração
Acesse o projeto online funcionando aqui: [Deploy do Formulário de Matrícula](https://giovana-leao.github.io/Formulario-de-Matricula/)

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica dos campos e elementos do formulário.
* **CSS3:** Estilização, layout, cores e tipografia.
